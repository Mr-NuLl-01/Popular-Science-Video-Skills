# 许可与公开边界

本仓库的原创技能文字和通用代码以 MIT 发布，由 Dot 生成与整理。第三方模型、依赖软件和任何素材保留自己的许可；MIT 不授予肖像、声音、商标、隐私或第三方版权的使用权，也不保证输出没有权利风险。

使用模型前核对模型卡、仓库、依赖和提供商条款；使用曲目/字体/图像前核对逐件来源、署名、改编、商业使用和再分发范围。公开可看、免费可下载、模型输出均不自动等于可随工程公开。

## 提交前最小检查

- 提交清单只有技能、文档、模板、必要代码、测试和一个通用合成案例。
- 不含视频/音频、照片/扫描、模型权重、字体、曲目、声音参考、embedding 或 cached prompt。
- 不含私有正文、项目资产、聊天记录、日志、账户、机器私人路径、访问令牌或文件服务标识。
- 不复制助手的隐藏指令、私有技能全文、内部工具实现或权限机制。
- 示例只含通用虚构文本、计时数字和测试产生的临时数据；不让真人声音或真实研究个案变成默认示例。
- `.gitignore` 只是防误提交提示，不是完整审查。核对实际待提交文件和历史，发现秘密应停止发布并处理，不靠新增 ignore 隐藏已经追踪的文件。

工作中的素材台账可使用模板记录私人资产，但填好的真实项目台账不能因此自动发布。仅向获准的具体人员/服务传输私人声音或素材，明确数据、目的与保存边界。
