## 公开版可复跑检查

当前公开测试套件共 27 项，均通过（本次 FFmpeg 可用，没有跳过媒体集成项）。

测试环境：Linux、Python 3.12.14、FFmpeg/ffprobe 7.1.5。没有下载模型、真实声音或外部媒体；测试中的短媒体由 FFmpeg 在临时目录生成，结束后移除。

```bash
python -m unittest discover -s tests -v
python -m compileall -q skills/produce-science-videos/scripts tests
```

- 累计样本时钟：24 kHz/30 fps、有理数帧率、大量亚帧片段、完整尾部覆盖、错误输入。
- 字幕：UTF-8 与断行、精确毫秒时间、逆序/重叠/精度坍缩拒绝。
- 清单：创建、原目录与隔离复制恢复核对、损坏/额外文件、路径穿越、重复条目、符号链接拒绝。
- FFmpeg：合成短片整段解码、复制流的压缩包一致、只改变音量后音频包不同而视频包仍一致。
- Qwen3 runner：标准库任务/路径/签名、合成 WAV 文件验证、纯 dry-run、损坏/孤立/不匹配拒绝、无覆盖发布及锁；不加载模型权重。

FFmpeg 未安装时媒体集成测试会明确跳过。其他单元测试通过不应写成媒体集成通过。技能入口已做名称、frontmatter 和引用可达性检查。

另一次独立临时副本检查完成了新手最小案例与恢复路径：27/27 测试实际通过；最小计时得 48000 样本、60 帧（31/29 帧）；ZIP CRC、隔离解包与清单校验通过，重建 SRT/时间轴与原结果完全一致。还用 FFmpeg 合成 1920×1080 测试画面并实际裁出中央 1440×1080，核对了 x=240…1680 的 4:3 区域。均未使用真实声音、照片或模型。

## 未验证与不承诺

- 本次没有执行泛化 runner 的真实 GPU/CPU 推理，没有做声音自然度试听或推理速度基准。
- 本次没有重做完整长视频，也没有验证其他助手、编辑器、云服务镜像或操作系统的端到端适配。
- 泛化 runner 不复刻历史环境的特定兼容修补；新部署可能需要按官方文档排查版本问题。
- 同一 seed 不保证不同设备、算子、模型 revision 或库版本的逐样本结果一致。
- 文件可解码、哈希相同、字幕导出成功，都不等于科学准确、视听满意或已获用户批准。
- 云 CPU 曾表现很慢，这只是生产经验，不是可用于估时的基准。

## 新环境的最小验收

先完成一个短段：核对环境与模型来源 → dry-run → 真实推理 → 实际听审 → 中断/续跑 → 最新字幕与音轨绑定 → 小片渲染和尾部检查 → 隔离恢复。只有这一链路在目标环境实际通过后，才扩大到整集或批量制作，并记录未通过的项目。
