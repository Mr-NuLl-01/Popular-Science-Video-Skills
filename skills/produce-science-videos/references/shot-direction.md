# 镜头叙事、视觉变化与空间连续性

## 从问题或音乐进入

先确定本片是解释型、音乐驱动型还是混合型；三者都要保留科学主张与来源。无旁白音乐短片按委托跳过 TTS 和非必要字幕；不需要先虚构一篇旁白。解释型用“现象 → 疑问 → 操作/推理 → 可见证据 → 回答”组织镜头；音乐驱动型先标乐句、铺垫、重音、高潮、停顿与收束，再让对象和故事随之发展。不要把所有视频剪成同一种速度。

音乐驱动段落可以承担情绪、尺度或悬念，不要求每镜都独立解释因果，但科学对象与动作不能制造错误理解。

给每段写一句“观众看完多知道什么或感受到什么”。把它落实为对象的初态、动作与结果。开头先给具体异常、动作、尺度或悬念，让观众有值得继续看的问题；不要默认用常驻标题、定义卡或概念清单开场。视觉吸引力不能靠夸大研究结论。

在低成本动态分镜中先走完一条完整叙事弧，检查声音节点与动作落点，再制作昂贵素材。快节奏可以通过同镜头内变化、运动加速、构图揭示和多场景蒙太奇实现；不是强制每 0.5 秒切镜。复杂证据、公式和首次出现的对象必须有辨认时间。

## 用视觉语法解决信息问题

为镜头选择理由，不设“每片必须几种”的配额：

| 观众需要 | 可用表达 | 要保持的锚点 |
|---|---|---|
| 理解对象处于哪里 | 环境远景到装置中景 | 对象位置、方向、环境关系 |
| 看到作用发生 | 接触点特写、剖面、局部展开 | 对象身份、力/运动方向 |
| 理解看不见的关系 | 原理图、数据、尺度切换 | 映射关系、单位、图例 |
| 看清前后差别 | 固定机位对比、并列、同坐标叠加 | 机位、比例、时间/参数基线 |
| 跟随一次推理 | 选择局部→变成曲线→计算→返回原对象 | 选区/颜色/标识的对应 |
| 感受推进和收束 | 景别、场景、疏密与运动变化，回扣开头 | 主题对象或视觉母题 |

连续几个镜头若都只有“居中主体 + 同色背景 + 粒子 + 缓慢推近”，逐一检查是否真的增加信息。粒子、光效、抖动、标题换字和随机换背景不是独立叙事。可用真实实验、史料、人物行为、环境、装置细节、机制动画与数据互相承接；不为凑素材种类插入无关画面。

把原因和结果尽量放在同一视野或可追踪的连续变化里。观众应看得见下一张图从哪里来。图表比较时可固定镜头；静态史料与长镜头并不天然是 PPT。避免无意义的全屏公式卡轮换和无铺垫的明暗底色跳变；统一画风不等于所有镜头同一构图。参考作品展示的多种风格可作为不同项目的选型库，不要求在同片随机轮换画风；本片先锁定材质、色彩与对象设计，再丰富景别、场景与动作。

## 先选生产方式，再许诺运动

- **真实素材**：适合记录真实实验、人物与历史证据；核验来源、剪辑上下文、时间与许可。
- **新建生成场景**：适合重建、气氛和难以拍摄的意象；先设计构图与空间，不把生成图称为实验记录。
- **已有图像的编辑**：保留认可的机位、对象、材质和光线，列出只改哪些区域及必须保持哪些结构。换视角不是局部贴图修补；源图缺少背面或被遮挡结构时，不假称裁切/变形已获得真实新视角。
- **分层 2.5D**：适合有限视差与局部运动；显式补齐遮挡背景，限制运动范围。大幅环绕、俯仰或展示新表面需重新构建/生成并审空间，不用整幅缩放或拉伸冒充。
- **程序化/三维/逐帧**：适合精确几何、图表、机制与接触运动。选择能控制关键约束的方法；不要仅因方便就用基础图元拼完所有叙事。

空间运动先用无纹理灰模或少量可辨认对象测试，覆盖最大俯仰、最近距离与最大位移，再投入材质和粒子密度。灰模通过后，最终合成还需重检。

先为风险最大的镜头做短样段：包括起点、运动极值、接触点、结果和退出，而不只交一张漂亮首帧。不能稳定实现的运镜应缩小范围或换有同等解释力的方案，避免批量复制缺陷。

## 镜头空间约定

每个实验/装置镜头在镜头表或单独镜头卡记录：

1. 世界坐标的上方向、表面法线、重力方向；机位相对主体的位置和高度、注视点、景别/视场或正交模式，固定机位还是实际运镜。
2. 画面可见表面、地平线/消失方向、前后关系；关键物体的相对尺寸与支撑结构。
3. 光源方向、投影、接触点、遮挡次序，以及保持不动的背景锚点。
4. 动作起止、施力/运动方向、接触时刻与结果；哪些变化是示意、慢放或时间压缩。
5. 跨镜头要保留的方位、动作轴、物体身份和状态。主动换轴或换场时先建立新方位。

三维实现检查深度测试、正反面与遮挡；2D/2.5D实现限定允许的视点范围，显式定义图层遮罩和可见性，越界时重建空间或简化分镜。

固定机位段落锁定投影与背景，主体运动不能带着背景意外缩放、漂移或旋转。真正运镜则需近远物体产生相符的视差，遮挡和可见表面随视点合理变化；不要把所有图层同速平移当成环绕。

### 回归案例：方形板与颗粒

先画简单侧视关系图，明确镜头在板面上方、近板面还是下方。可用相机到板平面的有符号距离判定顶面侧/底面侧；低机位不一定在板下。“仰视”应由镜头相对板面的高度与朝向决定，不能仅把上表面压成梯形就宣称从下看。

对于不透明板，镜头位于板面下方时通常看到底面/边缘，上表面的颗粒被板遮挡；边缘上方露出的颗粒是否可见仍取决于具体几何。若叙事需要完整展示上表面颗粒图案，改为有解释的俯视/斜上方机位，或明确使用透明/剖面示意，不能把两种视点拼成一个不可能的画面。

从上方落向板面的颗粒应遵循一致的世界重力方向、碰撞面与遮挡；相机变换后屏幕轨迹不必始终朝屏幕下方。物体、颗粒、相机、阴影使用一致的坐标和时间，落定后与板的坐标和透视一致，不能穿板、浮在板下或随镜头贴屏移动。先声明颗粒是实拍、经验证模拟、机制示意或装饰；插值到目标纹样不等于求解了物理轨迹。若展示振动导致的分布变化，区分示意运动与真实记录，不暗示未经验证的瞬时成图或运动机制。逐看四角、厚度、支架、颗粒接触/投影及运动极值，并连续播放确认没有机位跳变。

## 参考作品的使用边界

记录作品链接、可访问版本、实际观看时间范围、是否获得音频。把“看到的现象”“表达方式的解释”“拟用于本片的改法”分开；不能从封面、缩略图或帖子文字推断全片剪辑与声音。无法播放时明确未核验，并先使用独立成立的制作原则。

学习对象连续变换、镜头目的、节奏结构与信息组织，不复制独特构图序列或素材。公开技能仅保留原创归纳与必要链接；不要附第三方原视频、截图、音轨或私人审片材料，除非另有明确再分发权。
